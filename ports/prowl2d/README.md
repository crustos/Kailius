# Kailius Mini (Prowl2D)

The same short level as the Unity mini, written in the C# subset that [Prowl2D](https://github.com/crustos/Prowl2D)
translates to C, so it ships as a native executable with **no .NET in it**. Generated by `build.py mini prowl2d`:
`Cfg.cs` and `Level.cs` are produced from the Kailius Unity project and `ports/common/mini_level.json`; the
other files are hand-written in `ports/prowl2d/`. Do not edit this folder in place.

## Build and run

    python3 build.py mini prowl2d --build --prowl2d /path/to/Prowl2D

That runs Prowl2D's `player` command on `KailiusMini2D/`, runs the native result, and requires its output to be
identical to the same game running on .NET (`--verify`). It needs, once, in the Prowl2D checkout:
`python3 build.py deps --ccsharp`, `python3 build.py native`, the .NET 10 SDK (only the translator uses it),
and a C compiler. Afterwards `player/` rebuilds with a C compiler alone (`make static`).

## What it is

A headless, bot-driven run: Prowl2D has no input, audio, textures or native window yet, so `BotScript` plays
the level through the same `InputState` seam a keyboard would use, and the game prints its progress.
Nothing is drawn.

| Original script | Here | Notes |
|---|---|---|
| `PlayerController` | `PlayerScript` | speed, jump, damage, health and cooldown read from the prefab |
| `Patrol` + `Enemy` | `EnemyScript` (patrol) | speed, health and collider from the prefab; turns at ledges and walls; a stomp does 100 damage |
| `Boss` + `BossRun` + `BossWeapon` | `EnemyScript` (boss) | runs at the player within 15, swings after a wind-up for the prefab's damage |
| `Traps` | solid tiles that cost 25 and respawn you | from the scene's trap tilemap |
| `Coin` | `CoinScript` | score value from the prefab |
| `Portal` | `PortalScript` | reaching it wins |

Differences from the Unity mini: platforms are solid (Prowl2D has no one-way platforms yet), colliders
have no sprite offset because nothing is drawn, and Kailius's capsule colliders become 8-point polygons
with the same width and height (the runtime has box, circle and convex polygon only).
