# Kailius mini, authored scene

Generated by `python3 build.py mini unity --authored`. The level and characters are written into
`Assets/Scenes/KailiusAuthored.unity` as real GameObjects (`SpriteRenderer`, `Rigidbody2D`, `BoxCollider2D`,
`CircleCollider2D`), one PNG per sprite in `Assets/KailiusAuthored/Sprites`, tags in `ProjectSettings/TagManager.asset`.
Nothing is built at run time, so a tool that packs the authored scene sees everything that is drawn.

Scripts (`Assets/KailiusAuthored/Scripts`) are deliberately plain: public fields the generator fills in, no `AddComponent`,
no arrays or helper classes.

| Script | Does |
|---|---|
| `AuthoredPlayer` | Horizontal/Jump input, double jump, stomp or respawn on enemy contact, coins, hazards, portal |
| `AuthoredEnemy` | patrols between `minX` and `maxX` (computed from the ground under it) |
| `AuthoredCamera` | follows `target` |

Differences from the run-time-built mini (`ports/unity`): sprites are static (no animation yet), one-way platforms are
solid (no `PlatformEffector2D`), no HUD (score goes to `Debug.Log`), no sounds.

Pack it: `python3 tools/unity_pack.py <this folder> -o out` (plain, `--hybrid` and `--managed` all pack and draw).
