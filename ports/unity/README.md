# Kailius Mini (Unity)

A small playable slice of Kailius, generated by `build.py mini unity` from the original game's art and sounds.
Do not edit it in place: it is rebuilt from `ports/unity/` in the Kailius repo and replaced on every run.

## Run it

1. Unity Hub: **Add > Add project from disk**, pick this folder (`ProjectVersion.txt` names the editor version).
2. Open `Assets/Scenes/KailiusMini.unity` and press **Play**.
   If the scene fails to load, use the menu **Kailius > Recreate Mini Scene**.

Controls: **A/D** or arrows to move, **Space** to jump (once more in the air), land on enemies to hurt them
(a slime dies at once, a boss takes five stomps), **R** to restart.

## What is ported

The level, the enemies and every number come from `Assets/Resources/Kailius/level.json`, which `build.py` writes from
the Kailius project (the same data the Prowl2D and Stride2D ports use). The art is `atlas.png` next to it: the real
Kailius sprites cropped and scaled to 32 pixels per unit, cut into sprites at runtime by `MiniAssets`.

| Original script | Mini version | Notes |
|---|---|---|
| `PlayerController` + `Stats` | `MiniPlayer` | move, jump, double jump, contact damage with cooldown, knockback, health, all from the prefab |
| `Patrol` + `Enemy` | `MiniEnemy` (patrol) | walks, turns at ledges and walls, health and speed per prefab |
| `Boss` + `BossRun` + `BossWeapon` | `MiniEnemy` (boss) | chases within 15 units, winds up, hits in weapon range, cools down, health bar |
| `Traps` | `MiniHazard` | 25 true damage, then back to the respawn point |
| `Coin` | `MiniPickup` | +10 score, +1 coin |
| `Portal` | `MiniPortal` | ends the level instead of loading the next scene |
| `Flame1` prefab | `MiniGame.BuildTorch` | stick plus animated flame |
| `ScoreManager`, UI | `MiniGame` | score, coins, kills, HP bar and text via `OnGUI`, death and level-complete banners |

Differences from the original: the level is built at runtime from data instead of authored scenes, enemies are hurt by
stomping rather than the sword/bow, the ground is the nine-tile grass block tiled to size, and the HUD is plain `OnGUI`
instead of TextMeshPro. Not ported: ranged attackers (wizards), hearts, swords, shields, chests, enemy drops, parallax.

`python3 build.py mini unity --scene <name>` builds the same project from a real Kailius scene instead of the mini level.

## Build a player from the command line

    Unity -batchmode -nographics -quit -projectPath . -buildTarget linux64 \
          -executeMethod KailiusMini.EditorTools.MiniBuilder.Build -kailiusOut Builds
